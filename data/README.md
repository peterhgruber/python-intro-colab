# Datasets for python-intro-colab

Overview of the datasets for this course

## student.csv
This synthetic dataset contains the records of **210 fictional students**. Each row represents one student, while each column contains one characteristic or exam score.

The variables are:

* `id` – unique student identifier (integer)
* `isMale` – gender indicator (dummy variable with 1 = male, 0 = female)
* `isCity` – place of residence (dummy variable with 1 = city, 0 = rural)
* `math`, `stat`, `econ`, `art`, `engl` – exam scores (0–100) in Mathematics, Statistics, Economics, Art, and English (real)

The dataset is artificially generated for teaching and practice purposes. It does not contain any personal information.
